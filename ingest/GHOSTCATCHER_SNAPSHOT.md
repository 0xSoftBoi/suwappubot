# GhostCatcher temporary read-only snapshot

This temporary research service exports only public-chain facts normalized from Suwappu's Solana RPC collector. It contains no strategy scores, private user records, credentials, or attribution labels.

- [metadata](https://ghostcatcher-chain-export-v2-production.up.railway.app/metadata.json)
- [wallet roles](https://ghostcatcher-chain-export-v2-production.up.railway.app/wallets.csv)
- [conservative balanced token flows](https://ghostcatcher-chain-export-v2-production.up.railway.app/balanced_token_flows.csv)
- [signer ↔ mint co-occurrence](https://ghostcatcher-chain-export-v2-production.up.railway.app/signer_mint_edges.csv)
- [signer ↔ program co-occurrence](https://ghostcatcher-chain-export-v2-production.up.railway.app/signer_program_edges.csv)

The service is temporary and should be removed after the GhostCatcher dataset snapshot is committed.
