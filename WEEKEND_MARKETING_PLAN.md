# Weekend Marketing Plan — Suwappu Bot

> Actionable tasks for Saturday + Sunday. Focus: activate existing growth mechanics, create visibility, drive first users into the referral flywheel.

---

## Saturday: Foundation & Content

### 1. Twitter/X Launch Thread (2-3 hours)

Create and post a launch thread from the project account. Structure:

1. **Hook tweet**: "We built a cross-chain DEX that lives inside Telegram. 7 chains. One bot. Zero app downloads." + screenshot of Mini App
2. Supported chains (ETH, BSC, Polygon, Arbitrum, Optimism, Base, Solana) with visual
3. 30% lifetime referral commissions — highlight this is higher than most competitors
4. Gamification system — levels, daily streaks, leaderboards, fee discounts
5. AI agent interoperability (A2A protocol) — differentiation angle
6. TEE-backed wallets / security story
7. CTA: "Try it now → t.me/SuwappuBot" + referral link

**Assets needed:**
- 3-4 screenshots of the bot in action (swap flow, wallet, portfolio, Mini App)
- Chain logos graphic
- Referral earnings example

### 2. Set Up Social Presence (1-2 hours)

- **Twitter/X**: Bio, pinned tweet (the thread), profile pic (sakura logo), banner
- **Discord or Telegram group**: Create a community channel for users. Pin the referral program rules and leaderboard
- Link social accounts in the bot's `/start` menu if not already present

### 3. Landing Page at suwappu.bot (2-3 hours)

A simple single-page site (can deploy via Vercel/Netlify from the existing webapp infra). Sections:

| Section | Content |
|---------|---------|
| Hero | "Swap tokens across 7 chains from Telegram" + CTA button to bot |
| How it works | 3-step visual: Open bot → Connect wallet → Swap |
| Chains | Logo grid of supported networks |
| Referral | "Earn 30% of all fees from users you refer. Forever." |
| Gamification | Level tiers with fee discount table |
| Security | TEE wallets, encryption, non-custodial angle |
| Footer | Links to bot, docs, Twitter, community |

If a full landing page is too ambitious for one day, create a **Linktree-style page** with:
- Bot link
- Docs link
- Twitter
- Community group
- Referral program explainer

## Sunday: Distribution & Activation

### 4. Seed the Referral Program (1-2 hours)

- Generate 5-10 referral codes for early promoters / friends
- Create a "Founding Referrer" tier — first 50 referrers get highlighted on the leaderboard
- Post referral codes in relevant Telegram groups (DeFi, trading, crypto alpha groups) with a short pitch:

> "Cross-chain swaps inside Telegram. 7 chains, < 30 seconds. Earn 30% of fees from everyone you refer — forever. Try it: t.me/SuwappuBot?start=CODE"

### 5. Target Crypto Telegram Communities (2-3 hours)

Identify and engage with 10-20 active Telegram groups in these categories:
- DeFi trading / alpha groups
- Chain-specific communities (Solana, Base, Arbitrum are high-activity)
- Telegram bot user groups (existing users of trading bots)
- AI/agent communities (the A2A angle is a differentiator)

**Approach:** Don't spam. Provide value first — answer questions about cross-chain swaps, then mention Suwappu when relevant. Have 2-3 people from the team each cover different groups.

### 6. Crypto Twitter Engagement (ongoing)

- Quote-tweet and reply to relevant threads about:
  - Cross-chain swaps / bridging pain points
  - Telegram bots / Mini Apps
  - DeFi aggregation
  - AI agents in crypto
- Use the A2A/agent angle in AI-focused communities — this is genuinely novel

### 7. Reddit & Forum Posts (1 hour)

Post in:
- r/cryptocurrency (if allowed, or in daily discussion)
- r/defi
- r/solana, r/ethereum, r/0xPolygon
- Relevant Discord servers with bot-showcase channels

Frame as: "We built this, here's what it does, feedback welcome" — not a sales pitch.

### 8. Activate the Points System as a Launch Event (1 hour)

If not already live, configure a **launch weekend bonus**:
- 2x XP on all swaps this weekend
- 100 bonus points for first swap
- Daily check-in streak starts now — "Day 1 of Suwappu"
- Post the leaderboard publicly on Twitter at end of weekend

This can be done by temporarily adjusting point values in the points service config.

## What NOT to Do This Weekend

- Don't pay for ads yet — validate organic interest first
- Don't promise token launches or airdrops
- Don't spam — get banned from communities and you lose that channel permanently
- Don't over-engineer the landing page — a clean single page beats a half-finished site
- Don't ignore users who try the bot — fast response to feedback this weekend is critical

---

## Post-Weekend Follow-Up (Monday)

- Compile metrics from the weekend
- Identify which channels drove the most users
- Follow up with anyone who gave feedback
- Plan the next week's content calendar based on what worked
- Consider a "Week 1 recap" thread on Twitter with real numbers
