## 12. AgenC ($AGENC, @a_g_e_n_c) — winner #12

**What it does:** Best-documented of this batch — a Solana on-chain marketplace protocol where users/companies post one-off tasks or standing services with **SOL escrowed on-chain**; AI agents (or humans) claim and deliver work; settlement enforced by a Solana program rather than a centralized intermediary. Program-owned escrow, moderation gates, creator review workflow, 5% protocol fee with configurable settlement splits, public REST API, SDK/CLI/MCP integration, worker runtime. The `agenc-coordination` program has reportedly been **live on Solana mainnet since June 11 2026**, exposing 99 instructions. Live reference marketplace at agenc.ag. [agenc.tech](https://agenc.tech/), [github](https://github.com/tetsuo-ai/agenc-protocol)

**Team:** Explicitly "a tetsuo.ai project" — built by the team behind the existing **Tetsuo** Solana AI/dev-tooling project ($TETSUO), self-reported community of 32,000+ low-level-systems/ML developers. No individual founder named for AgenC itself; tetsuo.ai's team page returned HTTP 521. `@7etsuo` ("tetsuo.agenc") appears to be a core contributor handle. [solanacompass](https://solanacompass.com/projects/tetsuo)

**Token & market:** **$AGENC** on Solana/PumpSwap. ~$0.0007048, mcap ~$708K, 24h vol ~$50K. **-11.6% 24h, -11.3% 7d.** ATH $0.003547, ATL $0.0003967 — **~80% below ATH**, ~78.5% above ATL. Contract surfaced as `bumh6yebpbvah4by4otgjuvzq9cvh6dqpgrzvxfdmwc1` on PumpSwap — ⚠️ **UNVERIFIED**, DexScreener/GeckoTerminal both returned 403.

**Traction:** A named, dated mainnet program with a specific instruction count (99) is a concrete, checkable technical claim — far more falsifiable than the other two winners' claims (not independently confirmed on-chain in this pass). Team publicly posted a breakdown of how they spent the $250K prize (Aug 5 2026); existence confirmed, content unverified (x.com fetch returned 402).

**Funding:** $250k from Pump Fund at $10M valuation. Nothing else found.

**Links:** agenc.tech, agenc.ag (live marketplace + docs at agenc.ag/docs); GitHub [tetsuo-ai/AgenC](https://github.com/tetsuo-ai/AgenC), agenc-protocol, **agenc-core (private)**, agenc-plugin-kit; X @a_g_e_n_c; Telegram t.me/agenc_community.
