Positioned as a "Game Creator Launchpad" — AI-assisted game dev tooling plus analytics/component libraries for Roblox devs. [dextools](https://www.dextools.io/news/bloxapi-wins-pump-fun-hackathon-250k-investment)

**Team:** Entity listed as "SoulSeed, LLC." No named founders found in any source. X `@BloxApi` created Dec 20 2025 (just before the hackathon window), 2,247 followers, generic bio "Building blocks for what's next." **UNVERIFIED / likely anon team.**

**Token & market:** BLOXX on Solana/PumpSwap, CA `B1rGc4HM4Q6q4nU78ADM7fGguxqiasH53fh6ViDXpump`. Per CoinGecko (Aug 14 2026): $0.0001272, mcap **~$127K**, ATH $0.001402 (Apr 23 2026) — **down 90.9% from ATH, essentially at all-time low**, 30d -73.2%. [coingecko](https://www.coingecko.com/en/coins/bloxapi)

**Traction:** No verifiable game integrations, dev-adoption numbers, or usage stats on bloxx.gg beyond a landing-page tagline. GitHub search surfaces only unrelated pre-existing "BloxAPI" repos — no official org repo found.

**Funding:** $250K from Pump Fund at $10M valuation. Nothing else found.

**Links:** bloxx.gg; X @BloxApi; DexScreener `solana/5huhovgedzrleft7dvqg7ctfqo221bj5oben3egtbgmx`. No verified GitHub.

**Skeptical read:** Thin evidence of a real product — no docs, no named team, no traction metrics, price -91% from peak and at an ATL on the day of research. Narrative-driven token that pumped on hackathon news and has since bled out. **Highest vaporware risk in the cohort.**

## 5. ClawPump (CLAW, @clawpumptech) — winner #5

**What it does:** "Financial layer for autonomous AI agents" on Solana — lets AI agents launch tokens on pump.fun gaslessly, trade across 10+ DEXes, earn DeFi yield (Kamino/Drift), pay for compute via x402, and automate buyback/burn from revenue. Live docs, developer API, MCP server and SDK. Claims 2,700+ agent tokens launched via the platform, 80% fee share to agent creators. [clawpump.tech](https://clawpump.tech/)

**Team:** Co-founder named as **Mauricio Trujillo** (per a YouTube interview, "Solana, x402 & Eternal Agents with Bunny, Mauricio Trujillo of Clawpump"). X bio claims backing from @pumpfun and **@colosseum** (Solana's accelerator). Account created Feb 2 2026, 8,081 followers. Colosseum affiliation is a positive signal but unverified beyond the bio claim.

**Token & market:** CLAW on Solana/PumpSwap, CA `739dnZEG4yaBWFsY8L8ZwrfhGG6dhtCSercW8Umspump`. ~$0.0026–0.0035 depending on snapshot, mcap **~$2.2–2.6M**, ATH $0.007530 (Jul 8 2026, -65.5% from it), ATL $0.0002246 (Mar 8 2026) — **up ~1,055% from ATL**, 30d +33%, 7d +26%. Unlike most of the cohort, trending up. [coingecko](https://www.coingecko.com/en/coins/clawpump-tech)

**Traction:** Live site with a working product surface (agent marketplace, docs, dev API) rather than just a landing page. The 2,700+ agents claim is self-reported, unaudited.

**Funding:** $250K/$10M hackathon; possible Colosseum accelerator tie-in (terms unverified).

**Links:** clawpump.tech; X @clawpumptech.

**Skeptical read:** Best-evidenced of this batch — functioning app surface, named co-founder, price appreciating rather than collapsing. Still a narrow, hype-adjacent niche ("agents launching their own tokens"); real usage could be wash-trading/bot-generated rather than organic. Moderate confidence it's a shipping product; traction numbers are unverified self-reports.

## 6. CodecFlow (CODEC) — winner #6

**What it does:** Open-source "Operator platform" for building/simulating/training/deploying robots and AI agents that control physical or digital systems. Concrete components: **Fabric** (Go; orchestration/serverless GPU compute, per-second pricing), **optr** (Python; VLA runtime plugging into existing ROS stacks, MIT), **SimArena** (browser robot simulator exporting to MuJoCo/Isaac Sim), **conductor** (TypeScript; agent controls a browser, streams to Twitch/RTMP), plus pano, replayer, novnc fork. [github.com/codecflow](https://github.com/codecflow), [codecflow.ai](https://codecflow.ai/)

**Team:** GitHub org shows one identified handle, **@s1lent4gnt** — anon-style pseudonym, no full name. ⚠️ Do not conflate with the unrelated YC W22 company "Codec" (codec.io, founder Merwane Drai).

**Predates the hackathon — CONFIRMED:** GitHub org repos date to **Jan–Apr 2025**; X `@codecopenflow` created **Jan 28 2025** — about a year before the hackathon opened. CoinGecko lists CODEC's **ATH at $0.04560 on Sept 14 2025** and ATL $0.001362 on May 23 2025, both well before the Jan–Jun 2026 hackathon. The token had already run a full pump-and-crash cycle *before* winning. [coingecko](https://www.coingecko.com/en/coins/codec-flow)

**Token & market:** CODEC on Solana/PumpSwap, CA `69LjZUUzxj3Cb3Fxeo1X4QpYEQTboApkhXTysPpbpump` (also a Peaq-chain address). ~$0.003060, mcap **~$2.3M**, **-93.3% from the Sept 2025 ATH** but +124.6% from ATL; 7d +21.8%, 30d +23.2% (recovering, likely on hackathon-win news).

**Traction:** Real, actively-maintained MIT-licensed open source — but modest by GitHub standards (single-digit to low-teens stars per repo). Site claims partnerships with Pump.fun, Hugging Face, peaq, Solana; these read as ecosystem listings, not paying customers. No disclosed robot deployments, user counts, or revenue.

**Funding:** $250K/$10M hackathon. No other round found (Crunchbase/PitchBook searches empty).

**Skeptical read:** Most technically substantiated of this batch (real, dated, MIT-licensed repos with actual functionality), but a **pre-existing project whose token had already crashed ~93%** before "winning" — the win looks like it revived a fading token rather than funding a new build. Anon founder, no customer traction disclosed. Legitimate small open-source robotics/agent-tooling project riding a second pump on the hackathon narrative; not a scam, not proof of commercial traction either.
