## 7. Dexter (@dexteraisol) — winner #7

**What it does:** Non-custodial payment/wallet infrastructure for AI agents built on the x402 protocol (HTTP 402 pay-per-call). Users get a passkey/face-scan wallet ("Dexter Wallet") with no seed phrase; agents get spending-capped "tabs"/cards metered per API call, settled on Solana (EVM via one-shot x402). Also ships an MCP server, a Cursor IDE plugin, voice-controlled swaps, and an **IETF Internet-Draft** ("open-tabs-passkey"). Claims to be a top x402 facilitator on Solana. [dexter.cash](https://dexter.cash/)

**Team:** "Dexter Intelligence DAO LLC" / "Dexter Labs Corporation." No named founders surfaced; CEO referenced only as `@BranchM`. **UNVERIFIED identity.**

**Token & market:** Ticker **DEXTER**, Solana/pump.fun, CA `EfPoo4wWgxKVToit7yX5VtXXBrhao4G8L7vrbKy6pump` — ⚠️ **unverified against a primary source** (DexScreener returned 403). One third-party source explicitly calls the token "little utility... appears to serve more as a community token," separate from the actual product. CoinCarp reported it not listed on major CEX/DEX at time of writing.

**Traction:** GitHub org [Dexter-DAO](https://github.com/Dexter-DAO) is genuinely active — 10 public repos, several updated within days of research (Aug 2026): dexter-mcp (11 stars), dexter-x402-sdk, dexter-connect, dexter-mainnet-proofs. **Strongest code signal in this batch.**

**Funding:** None beyond the $250k confirmed.

**Links:** dexter.cash; X @dexteraisol; GitHub Dexter-DAO; npm `@dexterai/x402`.

**Skeptical read:** Most real *product* of the three — active multi-repo GitHub, IETF draft, live deployed subdomains (stake.dexter.cash). But the token side is murky: contract unverifiable via primary source, anon leadership, and independent commentary says the token has little utility. **Code-real, token-speculative, team-anon.**

## 8. Clude (@cludeproject) — winner #8

**What it does:** "AI memory layer" for agents — persistent, portable agentic memory built on Stanford Generative Agents / MemGPT-style research, marketed as solving agent "goldfish memory." Also framed as tokenizing memory as an on-chain asset.

**Team:** Founder **Sebastien Sim** (@sebbsssss) — 5 years at Binance building Binance Card and Binance Pay from the ground up, plus prior AI work at ByteDance. Operates as "Clude Labs," reportedly engaging Singapore regulators on a "tokenized memory standard." [LinkedIn](https://www.linkedin.com/in/sebastiensim/) — **the most credible named founder in the whole cohort.**

**Token & market:** Ticker **CLUDE**, Solana, CA `7UDbgT6W6x5VPDZUeM4uHbKuuaULYFzMKHntBNuNMaUt`, trades on PumpSwap/Meteora, listed on KCEX (a CEX). Per CoinGecko: **$0.0004457**, mcap **~$445K**, 24h vol ~$43K, ATH **$0.004061 (May 30 2026)** — **down ~89% from ATH**. [CoinGecko](https://www.coingecko.com/en/coins/clude)

**Traction:** Self-reported "1.3M+ memories stored, 600+ agents integrated, 81.3% retrieval quality" — no independent verification found. Also placed 4th in a separate Colosseum agent hackathon.

**Funding:** None found beyond $250k.

**⚠️ Notable event:** Around the token's decline the team "extended the lock on 7% of team supply for another 2 months, bringing total locked supply to almost 20%" — framed as a commitment signal, but the phrasing ("in light of recent events") implies a negative community event triggered it. **The triggering incident could not be identified — UNVERIFIED.**

**Links:** X @cludeproject. No GitHub found (unverified whether one exists publicly).

**Skeptical read:** Real named founder with a plausible fintech resume, coherent technical narrative, live CEX listing — but token -89% from ATH, traction entirely self-reported, no public GitHub, and the supply-lock extension reads as damage control after an undisclosed incident. **Narrative-forward token with a real founder but thin verifiable product evidence.**

## 9. SolScanner (SCAN, @solscanner_app) — winner #9

**What it does:** On-chain wallet analytics for Solana: traces funding sources, maps wallet-to-wallet connections, detects "bundled" wallet clusters (coordinated buyers/insiders), resolves KOL/exchange/domain identities, AI-generated wallet-behavior summaries. Free tier (30 credits/mo) plus paid plans; Telegram bot (@solscnnr_bot). Site claims 125,000+ wallets analyzed, 2.8M connections mapped, 1.1K KOL wallets, 12K bundled wallets. [solscanner.app](https://www.solscanner.app/)

**Team:** Not disclosed anywhere. The site's About page has zero founder/team info; third-party trackers describe the team as "undisclosed." **Anon team.**

**Token & market:** Ticker **SCAN**, Solana/PumpSwap, primary CA `5Aru7v34QY1F69aWuY3mXKf5oxpg2CZNYcmo9hvPpump` (a second pair `ADjQyCe1VgqrMqySzEuihCpi4hjB6WFAjcFtYygrimyE` also surfaced — likely a second pool/migration, relationship unconfirmed). Mcap **$280K–$500K** depending on source (OKX $496K; Coinbase $501K; Solflare $282K). 24h volume as low as **~$1.89K** on one snapshot — very thin. ⚠️ **Solflare's built-in risk scanner has flagged the token**, and it is **not verified on Solana's token registry**. [OKX](https://web3.okx.com/token/solana/5Aru7v34QY1F69aWuY3mXKf5oxpg2CZNYcmo9hvPpump), [Solflare](https://www.solflare.com/prices/solscanner/5Aru7v34QY1F69aWuY3mXKf5oxpg2CZNYcmo9hvPpump/)

**Traction:** Product metrics above are self-reported. X @solscanner_app ~2,453 followers, joined February 2026 — young and small for a project funded at a $10M valuation.

**Funding:** None found beyond $250k.

**Links:** solscanner.app; X @solscanner_app; Telegram bot. GitHub/Discord claimed on-site but repo contents unverified.

**Skeptical read:** The product category (wallet-cluster/bundle detection) is real and useful, and the feature list is concrete rather than buzzwords — but this is the weakest-verified of the batch: fully anon team, no independent confirmation of usage, a token **flagged by a wallet risk scanner**, not on Solana's token registry, thin volume, small young social following. **Highest rug risk in this batch.**
