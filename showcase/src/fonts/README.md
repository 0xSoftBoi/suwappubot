# Self-hosted fonts

Latin-subset variable woff2 files, fetched once from Google Fonts so the build
has no network dependency (`next/font/local` in `src/app/layout.tsx` and
`src/app/next/page.tsx`). All three families are licensed under the SIL Open
Font License 1.1 (https://openfontlicense.org):

- Archivo (normal + italic, wght 100-900) - Omnibus-Type
- Newsreader (normal + italic, wght 200-800, opsz axis) - Production Type
- JetBrains Mono (normal, wght 100-800) - JetBrains
