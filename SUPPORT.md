# Support

## Getting help

- **Bug reports and feature requests**: open a GitHub issue on this repository with
  steps to reproduce, expected vs. actual behavior, and the surface involved
  (Telegram bot, webapp, agent API, showcase, mobile).
- **Security vulnerabilities**: do **not** open a public issue — follow
  [SECURITY.md](SECURITY.md) (email security@suwappu.bot).
- **Service status**: the status page on the showcase site (`/status`) reflects live
  service health; operators use `python3 scripts/status.py`.

## In-product support

- Telegram bot: the `/start` menu links to help; the webapp has a Support page.
- Enterprise inquiries: the contact form on the showcase site.
